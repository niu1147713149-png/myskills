# Design Nvwa - 智能设计路由系统

## 简介

Design Nvwa（设计女娲）是一个智能设计路由 skill，能够根据用户的需求自动判断最适合的设计路线，并调用相应的设计工具完成方案输出。

## 功能特点

### 🎯 智能需求采集
- 通过结构化问题引导用户明确设计需求
- 了解项目类型、风格偏好、规范要求等关键信息
- 一次一个问题，避免信息过载

### 🚦 三条设计路线

#### 路线 1：纯创意设计
- **适用场景**：追求独特性、视觉冲击力的项目
- **设计工具**：frontend-design
- **特点**：不受规范束缚，完全创意导向

#### 路线 2：纯参考设计
- **适用场景**：需要稳定、规范的设计
- **设计工具**：ui-ux-pro-max
- **特点**：基于成熟案例和最佳实践

#### 路线 3：创意与规范结合
- **适用场景**：既要创新又要规范的项目
- **设计工具**：ui-ux-pro-max + frontend-design
- **特点**：在规范基础上进行创意设计

### 📊 自动路线判断
基于关键词匹配和语义分析，自动识别用户意图并推荐最合适的设计路线。

## 安装方法

### 方法 1：本地安装（推荐）

1. 将 `design-nvwa` 文件夹复制到你的项目的 `.claude/skills/` 目录下：
```bash
cp -r design-nvwa /your/project/.claude/skills/
```

2. 重启 Claude Code 或重新加载项目

### 方法 2：从 GitHub 安装

如果你已经将 skill 上传到 GitHub，可以使用以下命令安装：

```bash
npx skills add https://github.com/niu1147713149-png/myskills --skill design-nvwa
```

## 使用方法

### 触发 Skill

在 Claude Code 中，当你需要进行设计相关的工作时，可以说：

```
我需要设计一个网站
```

或者明确调用：

```
请使用 design-nvwa skill 帮我设计
```

### 使用流程

1. **回答需求问题**
   - AI 会询问你的项目类型、风格偏好等信息
   - 一次回答一个问题即可

2. **确认设计路线**
   - AI 会根据你的回答推荐一条设计路线
   - 确认后 AI 将开始执行设计

3. **获取设计方案**
   - AI 会调用相应的设计工具
   - 最终呈现完整的设计方案

## 使用示例

### 示例 1：创意个人网站

```
用户：我想做一个个人作品集，要很独特，有艺术感

AI：你要设计的是什么类型的项目？
    A. 企业官网
    B. 电商平台
    C. 管理后台
    D. 个人作品集 ✓
    E. 其他

用户：D

AI：你希望设计风格是怎样的？
    A. 现代简约
    B. 科技感
    C. 艺术创意 ✓
    D. 传统商务
    E. 其他

用户：C

AI：关于设计规范，你的想法是？
    A. 需要严格遵循设计规范和最佳实践
    B. 完全不需要规范，追求独特创新 ✓
    C. 在规范基础上适当创新
    D. 不确定

用户：B

AI：根据你的需求，我建议采用【路线 1：纯创意设计】。
    这条路线会直接使用 frontend-design 工具，为你打造一个独特、视觉冲击力强的作品集网站。
    是否同意？

用户：同意

AI：[开始调用 frontend-design skill 进行创意设计...]
```

```

### 示例 3：品牌电商网站

```
用户：做一个电商网站，既要符合用户习惯，又要有独特的品牌风格

AI：根据你的需求，我建议采用【路线 3：创意与规范结合】。
    这条路线会分两步：
    1. 先用 ui-ux-pro-max 获取电商设计规范
    2. 再用 frontend-design 打造独特品牌风格

## 工作原理

```
用户提出需求
    ↓
探索项目背景
    ↓
需求采集（5个核心问题）
    ├─ 项目类型
    ├─ 风格偏好
    ├─ 规范要求 ← 关键判断依据
    ├─ 参考案例
    └─ 技术偏好
    ↓
关键词匹配 + 语义分析
    ↓
路线判断
    ├─ 路线1：frontend-design
    ├─ 路线2：ui-ux-pro-max
    └─ 路线3：ui-ux-pro-max → frontend-design
    ↓
执行设计
    ↓
输出方案
```

### 判断逻辑

路线判断基于关键词匹配：

```javascript
// 路线 1 关键词
["独特", "创新", "天马行空", "艺术", "不需要规范", "自由发挥"]

// 路线 2 关键词
["规范", "标准", "成熟案例", "稳妥", "不要太创新", "最佳实践"]

// 路线 3 关键词
["兼顾", "在规范基础上创新", "既要又要", "平衡"]
```

## 常见问题

### Q1: 如何切换设计路线？
A: 在 AI 推荐路线后，如果不满意，可以直接说"我想用其他路线"，AI 会重新判断或让你直接选择。

### Q2: 可以跳过问题直接设计吗？
A: 不建议。完整的需求采集能帮助 AI 更准确地判断路线，提供更符合你需求的设计方案。

### Q3: 如果对设计结果不满意怎么办？
A: 可以：
- 要求修改具体部分
- 切换到其他路线重新设计
- 提供更详细的需求说明

### Q4: 支持哪些项目类型？
A: 支持所有 Web 相关的设计项目，包括但不限于：
- 企业官网
- 电商平台
- 管理后台
- 个人作品集
- 博客网站
- 移动端应用

### Q5: 能否自定义路线判断规则？
A: 当前版本的判断规则固定在 SKILL.md 中。如需自定义，可以直接编辑 SKILL.md 文件中的关键词列表和判断逻辑。
